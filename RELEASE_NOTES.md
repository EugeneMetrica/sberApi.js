# Release Notes - v2.0.0

## Основные изменения

### Новая архитектура на TypeScript

Проект полностью переписан на TypeScript с использованием современных технологий:

- **TypeScript** - строгая типизация для надежности кода
- **Fastify** - высокопроизводительный веб-фреймворк
- **Grizzly ORM** - удобная работа с PostgreSQL
- **TypeBox** - валидация данных через TypeScript типы

### Мультитенантность

Система теперь поддерживает работу с множеством клиентов через мультитенантную архитектуру:

- Изоляция данных по tenantId
- Отдельная конфигурация Sber API для каждого тенанта
- Гибкая настройка через БД

### Улучшения

1. **Автоматическое управление токенами**
   - Автоматическое обновление истекших токенов
   - Сохранение токенов в БД
   - Поддержка refresh token

2. **Enterprise подход**
   - Разделение на слои (controllers, services, models)
   - Валидация всех входных данных
   - Централизованная обработка ошибок

3. **REST API**
   - Полный набор endpoints для работы с платежами
   - Управление токенами через API
   - Стандартизированные ответы

## Миграция с версии 1.0.0

### Изменения в API

Старый SDK (v1.0.0) работал напрямую с клиентами. Новая версия предоставляет REST API:

**Было:**
```javascript
const client = new ApiClient(config);
const token = await client.getAccessToken(...);
```

**Стало:**
```bash
curl -X POST /tokens \
  -H "X-Tenant-Id: tenant-1" \
  -d '{ "authorizationData": {...} }'
```

### Настройка

Необходимо:
1. Установить PostgreSQL
2. Настроить переменные окружения (.env)
3. Запустить миграцию БД: `npm run migrate`
4. Создать тенантов в БД

## Установка

```bash
npm install
npm run migrate
npm run build
npm start
```
