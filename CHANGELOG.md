# Changelog

Все заметные изменения в проекте документируются в этом файле.

## [2.0.0] - 2025-01-XX

### Добавлено
- Полная переработка на TypeScript
- Интеграция Fastify как веб-фреймворка
- Добавлена поддержка Grizzly ORM для работы с PostgreSQL
- Валидация через TypeBox схемы
- Мультитенантная архитектура с изоляцией данных
- Автоматическое управление токенами доступа
- Автоматическое обновление истекших токенов
- REST API для работы с платежами и токенами
- Middleware для извлечения tenant из заголовков/поддоменов

### Изменено
- SDK клиенты переписаны на TypeScript
- Архитектура изменена на enterprise подход с разделением слоев
- Улучшена обработка ошибок

### Технические детали
- TypeScript строгий режим включен
- Все зависимости обновлены до актуальных версий
- Добавлена поддержка миграций БД
